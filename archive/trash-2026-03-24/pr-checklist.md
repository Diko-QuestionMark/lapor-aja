# PR Checklist (Naming Hygiene)

- [ ] New file names use `kebab-case`
- [ ] New CSS classes use `kebab-case`
- [ ] New DOM IDs and `data-*` use `kebab-case`
- [ ] JS variables/functions are `camelCase`
- [ ] JS constants are `UPPER_SNAKE_CASE`
- [ ] No new ambiguous generic entrypoint names (for example `script.js`, `style.css`)
- [ ] `npm run check:naming` passes for core frontend
